Restore

This page lives in the ksatyaki/wayland-desktop repo together with every file it links. ./install.sh --all --packages rebuilds the desktop; ./install.sh --enable-hyprland, --enable-sway, --enable-bar, --enable-theming, --enable-login pick single parts (existing files are backed up). See the README.

Also on disk, no file to copy: ~/.local/share/keyrings/default contains login; ~/.config/kdeglobals is deliberately absent; folder handler set with xdg-mime default pcmanfm-qt.desktop inode/directory.

  • Hyprland decides the panel in Lua at config load (docked() scans hl.get_monitors() for an office description) and reloads the config on monitor.added / monitor.removed.
  • Sway uses kanshi profiles (laptop / home / office). Never run kanshi under Hyprland.
  • xwayland.force_zero_scaling = true in Hyprland: Proton games see the panel at 2560×1600. Sway always upscales Xwayland on a scaled output.
  • Names: hyprctl monitors or swaymsg -t get_outputs. Test a layout without saving: wdisplays.
  • Workspace 2 is pinned to the Lenovo; Windows programs (class steam_app_<id> or *.exe) always open there. Fixed workspaces: Emacs 2, Chrome 3, Telegram 4, MATLAB 5.

Add a launcher

  • Copy a custom/app-* block in both bar configs; set icon, tooltip-format, on-click.
  • Add its name to modules-left in both files and to the #custom-app-* selector list in style.css.
  • Write icons as \uXXXX escapes. Glyph codes: nerdfonts.com/cheat-sheet.

Wallpapers

waypaper (GTK picker, launch from Super+D) over the awww daemon. Folder ~/Pictures/Wallpapers. Both compositors autostart awww-daemon then waypaper --restore, which reapplies the last pick. hyprpaper and swaybg are not started.

Login screen

SDDM with sddm-astronaut-theme (Qt6 QML) and the doom preset. Install: clone github.com/Keyitdev/sddm-astronaut-theme into /usr/share/sddm/themes/, copy Fonts/* to /usr/share/fonts/, drop doom.conf into Themes/ and the background into Backgrounds/doom.jpeg, set ConfigFile=Themes/doom.conf in metadata.desktop. Font: fan-made Eternal UI (in Fonts/, installed to /usr/share/fonts/ by the script). Username prefilled, cursor in the password field. Lock screens (hyprlock, swaylock) reuse the wallpaper, font and colours. Preview: sddm-greeter-qt6 --test-mode --theme /usr/share/sddm/themes/sddm-astronaut-theme.

Gotchas

  • Sway needs --unsupported-gpu on the proprietary NVIDIA driver; the session file passes it.
  • Hyprland Lua: a monitor rule with disabled = false is ignored; the catch-all output = "" rule must be the last hl.monitor call; wiki spring curves use dampening, and there is no reload_config dispatcher (use exec_cmd("hyprctl reload")).
  • Bar icons must be \u escapes; raw private-use glyphs get stripped by some editors and tools. A custom module whose command prints nothing is hidden entirely.
  • Hyprland makes the last-connected input device the main keyboard; the bar's language module is pinned to at-translated-set-2-keyboard.
  • Breeze Qt style paints menu bars and toolbars from ~/.config/kdeglobals if it exists. Keep it deleted, or switch qt6ct to Fusion or Kvantum.
  • Bluetooth headset stuck in mono means the hands-free profile; reconnect to renegotiate A2DP. Any app opening the mic switches it back to mono.
  • Proportional fonts misalign Waybar modules; keep a monospace text font on the bar.
  • Brightness keys need the user in the video group: sudo usermod -aG video $USER. External monitor brightness goes over DDC/CI: install ddcutil, then apply its udev rule to the buses already there with sudo udevadm control --reload-rules && sudo udevadm trigger -s i2c-dev -s dri. Check with ddcutil detect; laptop panels never answer.
  • Session env: SDDM starts Wayland sessions through a zsh login shell, so ~/.zprofile reaches both compositors.
